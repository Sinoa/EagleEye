# MjlogReaderSample

MjlogReader ライブラリの使用方法を示すサンプルアプリケーションです。天鳳牌譜（mjlog）を読み込み、コンソールに対局情報を表示します。

## 概要

このサンプルアプリケーションでは、以下の機能をデモンストレーションしています：

- 牌譜ファイル（.mjlog / .xml）の読み込み
- XML文字列からの直接パース
- 対局ヘッダー情報の表示（プレイヤー情報、ルール）
- 各局（セッション）の詳細表示
- 行動ステップの表示（詳細モード）
- 和了・流局結果の表示

## 必要要件

- .NET 10.0 以上
- MjlogReader ライブラリ

## ビルド

```bash
cd src/MjlogReaderSample
dotnet build
```

## 使用方法

### 基本的な使い方

```bash
# ファイルから牌譜を読み込む
dotnet run -- path/to/game.mjlog

# XML形式のファイルを読み込む
dotnet run -- path/to/game.xml
```

### コマンドラインオプション

| オプション | 説明 |
|-----------|------|
| `file` | 牌譜ファイルのパス（.mjlog または .xml） |
| `-x, --xml <文字列>` | XML形式の牌譜文字列を直接指定 |
| `-v, --verbose` | 詳細な行動ステップを表示 |

### 使用例

```bash
# 基本的な表示
dotnet run -- game.mjlog

# 詳細モードで全行動ステップを表示
dotnet run -- game.mjlog -v

# XML文字列から直接読み込み
dotnet run -- -x "<mjloggm ver=\"2.3\">...</mjloggm>"
```

### ヘルプの表示

```bash
dotnet run -- --help
```

## コード構造

```
MjlogReaderSample/
├── ApplicationMain.cs       # エントリポイント・コマンドライン処理
└── MjlogReaderSample.csproj # プロジェクトファイル
```

### 主要メソッド

| メソッド | 説明 |
|---------|------|
| `Main` | エントリポイント、コマンドラインオプションを定義 |
| `HandleCommand` | 牌譜の読み込みと表示処理のメインハンドラー |
| `DisplayHeader` | 対局ヘッダー情報を表示 |
| `DisplaySessions` | 全セッションを表示 |
| `DisplaySession` | 個別セッションを表示 |
| `DisplaySteps` | 詳細な行動ステップを表示 |
| `DisplayResult` | セッション結果（和了/流局）を表示 |
