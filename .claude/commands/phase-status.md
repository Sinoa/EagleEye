# 開発フェーズ進行状況の確認

## 手順

### 1. TODO.md の読み込み

`docs/TODO.md` を読み込み、以下を把握する:
- 現在のフェーズ（Phase 0〜8）
- チェックリストの完了/未完了状況
- 既存実装への確認事項の状況

### 2. 進行状況の表示

以下の形式で表示する:

```
現在のフェーズ: Phase X - {フェーズ名}

完了済みタスク:
  - [x] タスク名

未完了タスク:
  - [ ] タスク名

進捗: X/Y (XX%)
```

### 3. ブロッカーの抽出

`docs/ARCHITECTURE.md` の §14「未解決課題・比較実験」を読み込み、現在のフェーズに関連するブロッカーを抽出する:

- 高優先度（現フェーズのブロッカー）
- 中優先度（次フェーズ以降）

### 4. 次のアクションの推奨

未完了タスクとブロッカーを踏まえ、次に着手すべきタスクを推奨する:
- 依存関係を考慮した優先順位
- 推奨理由の簡潔な説明
