## 概要

MjlogConverter は、天鳳の牌譜ファイルを読み込み、構造化された JSON 形式に変換するツールです。
内部で [MjlogJ ライブラリ](../MjlogJ/README.md) を使用しています。

### 特徴

- 単一ファイルおよびディレクトリの一括変換に対応
- ディレクトリ構造を維持した出力
- 進捗表示機能
- GZip 圧縮ファイルの自動検出

---

## ビルド方法

### 必要環境

- .NET 9.0 SDK

### ビルドコマンド

```bash
# プロジェクトのルートディレクトリで実行
dotnet build MjlogConverter/MjlogConverter.csproj -c Release
```

ビルド後の実行ファイルは `MjlogConverter/bin/Release/net9.0/` に出力されます。

---

## 使用方法

### 基本構文

```bash
MjlogConverter -i <入力パス> [-o <出力パス>] [-p]
```

または

```bash
MjlogConverter <入力パス>
```

---

## オプション

| オプション | 短縮形 | 説明 | 必須 |
|-----------|--------|------|------|
| `--input` | `-i` | 入力ファイルまたはディレクトリのパス | ✓ |
| `--output` | `-o` | 出力先ディレクトリのパス（省略時: 入力と同じ場所） | |
| `--progress` | `-p` | 進捗表示を有効にする | |
| `--help` | `-h` | ヘルプを表示 | |

## 使用例

### 単一ファイルの変換

```bash
# 入力ファイルと同じ場所にJSONを出力
MjlogConverter -i game.xml

# 出力先を指定
MjlogConverter -i game.xml -o output/
```

### ディレクトリの一括変換

```bash
# ディレクトリ内のすべてのXMLファイルを変換
MjlogConverter -i logs/ -o converted/

# 進捗表示付きで変換
MjlogConverter -i logs/ -o converted/ -p
```

### 進捗表示

`-p` オプションを指定すると、変換処理の進捗がリアルタイムで表示されます。

```
 / 処理中: game_001.xml 15/100 [=========>          ]
```

### 変換完了時の出力

変換処理が完了すると、処理結果のサマリーが表示されます。

```
処理完了: 100 ファイル成功, 2 ファイル失敗
```

## 出力形式

変換後のJSONファイルは、MjlogJライブラリの `JsonOutputFormatter` で出力されます。
詳細な出力構造については [MjlogJ README](../MjlogJ/README.md#json-出力構造) を参照してください。

### 出力ファイルの命名規則

- 入力ファイル: `game.xml` → 出力ファイル: `game.json`
- ディレクトリ構造は維持されます

### 例

入力:
```
logs/
├── 2024/
│   ├── game1.xml
│   └── game2.xml
└── 2025/
    └── game3.xml
```

コマンド:
```bash
MjlogConverter -i logs/ -o converted/
```

出力:
```
converted/
├── 2024/
│   ├── game1.json
│   └── game2.json
└── 2025/
    └── game3.json
```

## 注意事項

### サポートするファイル形式

- `.xml` ファイル（天鳳牌譜XML形式）
- GZip圧縮されたファイルも自動検出して処理可能

### エラー処理

- 変換に失敗したファイルがある場合、エラーメッセージが表示されますが、他のファイルの処理は続行されます
- エラーが1件以上ある場合、終了コード `1` が返されます
- 全ファイルが正常に処理された場合、終了コード `0` が返されます

### パフォーマンス

大量のファイルを処理する場合は、`-p` オプションで進捗を確認することを推奨します。
